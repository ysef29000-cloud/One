# One Rose — موقع العيادة

موقع صفحة واحدة (HTML فقط، من غير سيرفر ولا قاعدة بيانات) — يعني الاستضافة **مجانية 100%**.

## 1) ربط Meta Pixel
1. ادخلي على **Meta Events Manager** ← Connect data sources ← Web ← اعملي Pixel وخدي الـ **Pixel ID** (رقم 15–16 خانة).
2. افتحي `index.html` ودوّري على السطر ده وحطي الرقم مكان `YOUR_PIXEL_ID`:
   ```js
   window.ONE_ROSE = { PIXEL_ID: 'YOUR_PIXEL_ID', ... }
   ```
3. ارفعي الموقع، وجرّبيه بإضافة **Meta Pixel Helper** على كروم.

### الأحداث (Events) اللي الموقع بيبعتها تلقائي
| الحدث | امتى بيتبعت | تستخدميه في إيه |
|---|---|---|
| `PageView` | أي حد يفتح الموقع | جمهور "كل زوار الموقع" |
| `ViewContent` | تضغط على خدمة (ليزر / نضارة / جلدية / حقن) — ومعاه اسم الخدمة | إعادة استهداف كل واحدة بإعلان الخدمة اللي اهتمت بيها |
| `InitiateCheckout` | تضغط "احجزي الخدمة دي" | ناس قربت تحجز |
| `Contact` | تضغط واتساب أو اتصال | ناس اتواصلت |
| `Lead` + `Schedule` | تبعت فورم الحجز | **حدث التحويل** للحملات (Optimize for Leads) |
| `ScrollDepth` / `EngagedVisitor` | نزلت 50% / 90% من الصفحة، أو قعدت 30 ثانية | جمهور مهتم فعلًا (أدفى من مجرد زيارة) |

### جماهير إعادة الاستهداف المقترحة (Audiences ← Custom Audience ← Website)
- **زوار آخر 30 يوم** ما عملوش `Lead` ← إعلان "الكشف مجاني لسه متاح".
- **شافوا خدمة الليزر** (`ViewContent` و content_name = الليزر) ← إعلان عرض باكدج ليزر. وكذلك لكل خدمة.
- **EngagedVisitor** آخر 14 يوم ← إعلان آراء عميلات / قبل وبعد.
- **عملوا Lead** ← استبعديهم من إعلانات الاكتساب، واعملي منهم **Lookalike 1%** مصر.

## 2) النشر مجانًا
أسهل طريقة: **Netlify Drop** — افتحي app.netlify.com/drop واسحبي فولدر `website` كله. هياخد لينك مجاني فورًا (وممكن تغيّري الاسم لـ `onerose-clinic.netlify.app`).
بدائل مجانية: Cloudflare Pages، أو GitHub Pages (لو الريبو Public).
دومين خاص (`onerose-clinic.com`) اختياري ~ 10$ في السنة، وتربطيه بنفس الاستضافة المجانية.

> بعد النشر: في Events Manager ← Settings، ضيفي الدومين في **Traffic permissions**، ولو عندك دومين خاص اعمليله **Domain verification**.

## تعديل المحتوى
- الخدمات: مصفوفة `SERVICES` في آخر `index.html`.
- رقم الواتساب/الموبايل: `window.ONE_ROSE` في أول الملف.
- الصور: فولدر `assets/`.
